Глоссарий терминов SEO

Краткий словарь терминов, которые часто встречаются в материалах о поисковой оптимизации.

SERP
Search Engine Results Page — страница результатов поисковой выдачи.
Индексация
Процесс добавления страницы сайта в базу данных поисковой системы.
Семантическое ядро
Список поисковых запросов, по которым сайт планируется продвигать.
Canonical
Атрибут ссылки, указывающий поисковой системе основной адрес страницы среди дублей.
Core Web Vitals
Набор метрик Google, оценивающих скорость загрузки, интерактивность и стабильность вёрстки страницы.
Анкор
Текст ссылки, по которому пользователь и поисковый робот определяют её тематику.
Крауд-маркетинг
Размещение полезных упоминаний и ссылок на сайт в комментариях, на форумах и в сообществах.
