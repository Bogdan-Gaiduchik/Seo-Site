# SEO-Гид

**Ссылка на работающий сайт (GitHub Pages):** https://bogdan-gaiduchik.github.io/Seo-Site/

## О проекте

Учебный тематический сайт из 10 связанных страниц, посвящённый поисковой оптимизации (SEO):
что такое SEO, on-page и off-page оптимизация, техническое SEO, инструменты, кейсы,
локальное SEO, глоссарий терминов и контакты.


## Страницы сайта

- **Главная** — введение в SEO и обзор разделов
- **Что такое SEO** — основы поисковой оптимизации, виды SEO, этапы продвижения
- **On-page SEO** — внутренняя оптимизация: метатеги, заголовки, контент, изображения
- **Off-page SEO** — внешняя оптимизация: ссылочная масса, упоминания, E-E-A-T
- **Техническое SEO** — индексация, скорость загрузки, микроразметка, мобильная адаптация
- **Инструменты SEO** — обзор сервисов: Яндекс Вебмастер, Screaming Frog, Ahrefs, Wordstat
- **Кейсы** — примеры продвижения и видеоразбор SEO-аудита
- **Локальное SEO** — карточки организаций, отзывы, работа с локальными запросами
- **Глоссарий** — словарь терминов: SERP, canonical, Core Web Vitals и другие
- **Контакты** — форма обратной связи и реквизиты

## Технологии

- HTML5 (семантическая вёрстка)
- CSS3 (кастомные стили поверх фреймворка, методология БЭМ)
- Concise CSS — базовый фреймворк, подключён через CDN
- Vanilla JavaScript — бургер-меню для мобильной навигации



## Адаптивность

Вёрстка адаптирована по трём контрольным точкам:

- мобильные устройства — до 768px;
- планшеты — от 768px;
- десктопы — от 992px.

## Как запустить локально

Сайт полностью статический, сборка не требуется:

1. Скачайте или склонируйте репозиторий:
git clone https://github.com/Bogdan-Gaiduchik/Seo-Site.git

2. Откройте `index.html` в браузере — или запустите локальный сервер, например:
   npx serve либо через расширение Live Server в VS Code.


## Публикация на GitHub Pages

Проект опубликован по адресу: https://bogdan-gaiduchik.github.io/Seo-Site/

Если вы форкнули репозиторий и хотите опубликовать свою версию:

1. В настройках репозитория откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите источник **Deploy from a branch**,
   ветку `main` и папку `/ (root)`.
3. Сохраните — через 1–2 минуты сайт будет доступен по адресу
   `https://ваш_ник.github.io/Seo-Site/`.
