## Адаптивность

Вёрстка адаптирована по трём контрольным точкам:

- мобильные устройства — до 768px;
- планшеты — от 768px;
- десктопы — от 992px.

## Как запустить локально

Сайт полностью статический, сборка не требуется:

1. Скачайте или склонируйте репозиторий.
2. Откройте `index.html` в браузере — или запустите локальный сервер, например:
   ```
   npx serve .
   ```
   либо через расширение Live Server в VS Code.

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте туда содержимое проекта.
2. В настройках репозитория откройте вкладку **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник **Deploy from a branch**,
   ветку `main` и папку `/root`.
4. Сохраните — через 1–2 минуты сайт будет доступен по адресу вида
   `https://ВАШ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.
5. Вставьте эту ссылку в начало данного README.

## Что нужно доработать перед сдачей

- Заменить изображения-заглушки (picsum.photos) на собственные оптимизированные фото
  (JPEG/PNG/WebP), сохранив атрибуты `srcset`, `sizes`, `alt`, `title`.
- Заменить `src` у видео на странице `keysy.html` на реальную ссылку встраивания
  с RuTube/VK Видео.
- При необходимости — расширить и уточнить текстовый контент по своей теме.
- Проверить HTML и CSS валидатором W3C (https://validator.w3.org/,
  https://jigsaw.w3.org/css-validator/) и устранить критические ошибки.
