## О проекте

Учебный тематический сайт из 10 связанных страниц, посвящённый поисковой оптимизации (SEO):
что такое SEO, on-page и off-page оптимизация, техническое SEO, инструменты, кейсы,
локальное SEO, глоссарий терминов и контакты.

**ФИО студента:** Гайдучик Богдан Романович
**Группа:** 141-ПМо
**Тема проекта:** Поисковая оптимизация (SEO)
**Использованный CSS-фреймворк:** Concise CSS (https://concisecss.com)

## Технологии

- HTML5 (семантическая вёрстка)
- CSS3 (кастомные стили поверх фреймворка, методология БЭМ)
- Concise CSS — базовый фреймворк, подключён через CDN
- Vanilla JavaScript — бургер-меню для мобильной навигации

## Адаптивность

Вёрстка адаптирована по трём контрольным точкам:

- мобильные устройства — до 768px;
- планшеты — от 768px;
- десктопы — от 992px.

## Как запустить локально

Сайт полностью статический, сборка не требуется:

1. Скачайте или склонируйте репозиторий:
git clone https://github.com/Bogdan-Gaiduchik/Seo-Site.git

2. Откройте `index.html` в браузере — или запустите локальный сервер, например:
   npx serve либо через расширение Live Server в VS Code.


## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте туда содержимое проекта.
2. В настройках репозитория откройте вкладку **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните — через 1–2 минуты сайт будет доступен по адресу `https://bogdan-gaiduchik.github.io/Seo-Site/`.


## Реализованные требования

- 10 связанных страниц с единой структурой (`header`, `main`, `aside`, `footer`)
- Семантическая и валидная разметка HTML5
- Адаптивная вёрстка под 3 контрольные точки (мобильные, планшеты, десктопы)
- Бургер-меню для мобильной навигации (Vanilla JS)
- CSS-фреймворк Concise CSS + кастомные стили по методологии БЭМ
- Семантическая таблица с данными (страница «Инструменты SEO»)
- Встроенное видео с RuTube (страница «Кейсы»)
- Адаптивные изображения с `srcset` и `sizes`
- Формы обратной связи и подписки
- Осмысленный текстовый контент по теме
